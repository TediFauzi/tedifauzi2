Deskripsi Program
Program ini merupakan program sederhana menggunakan bahasa C yang berfungsi untuk melakukan pembaruan (update) nilai pada elemen array berdasarkan indeks tertentu.

Pada awal program, dibuat sebuah array bernama nilai yang memiliki 5 elemen dengan isi 10, 20, 30, 40, dan 50. Kemudian, variabel indeks diatur dengan nilai 3, sedangkan nilaiBaru diisi dengan angka 99.

Selanjutnya, program menjalankan perintah nilai[indeks] = nilaiBaru untuk mengganti elemen array pada indeks ke-3 menjadi 99. Setelah proses pembaruan selesai, program menggunakan perulangan for untuk menampilkan seluruh isi array.
